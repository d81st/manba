# CLAUDE.md

Энциклопедия ислама по первоисточникам. Полный план со всеми решениями — `docs/PLAN.md`. Прочитай его целиком в начале работы и перед любой крупной задачей; новые решения записывай туда.

## Что это за проект

Веб-приложение, где человек изучает ислам по первоисточникам: библиотека текстов с постоянными адресами фрагментов, энциклопедия с интерактивной подачей, карта Корана, словарь терминов, жизнеописание пророка, священные города, сложные темы, связи с другими религиями, ислам и наука, историческая линия, тесты и ассистент по источникам. Дебаты — во второй фазе.

Автор проекта сам изучает ислам и не принадлежит ни к одной стороне. Цель — показать всё как есть.

## Главные принципы (не нарушать)

1. **Все стороны.** Если взгляды расходятся (сунниты и шииты, течения, традиция и исследователи, разные учёные), показываются все, каждый со своими источниками. У каждого мнения видна степень признания: принято традицией / принято большинством исследователей / гипотеза меньшинства. Интерфейс и его тексты нейтральны.
2. **Только источники.** Любое утверждение на сайте ссылается на адрес фрагмента. Не придумывай и не генерируй религиозный контент: тексты, переводы, толкования, даты, связи, вопросы тестов. Тестовые данные в коде помечай как вымышленные.
3. **Порядок опоры:** оригинал → утверждённый перевод → видео как дополнительный материал. Видео не является аргументом.
4. **Уровни авторитетности** ведутся отдельно для суннитского и шиитского канонов; Коран — высший уровень для обоих.
5. **Неизменность после запуска.** На этапе разработки всё можно менять. После запуска опубликованный текст не меняется: исправления — новой версией с журналом (кто, когда, почему). Добавлять новое можно всегда.

## Ключевые понятия модели данных

Схема адресов — в разделе «Схема адресов (черновик)» плана; её нужно утвердить с автором (и его специалистом) **до** первой миграции базы.

- Произведение: постоянный id (`quran`, `bukhari`), канон (общий / суннитский / шиитский / внешний), уровень авторитетности, своя схема уровней (сура → аят; книга → глава → хадис).
- Адрес: читаемый («Коран 2:255») и машинный (`quran.2.255`), диапазоны (`quran.2.255-257`). Адреса никогда не переименовываются и не переиспользуются.
- Таблица альтернативных нумераций изданий (особенно для хадисов).
- Версия текста: язык, тип (оригинал / кираат / перевод), переводчик, источник, **лицензия**, статус сверки, признак главной. Для Корана главная — Хафс от Асима.
- Смысловые переводы содержат вставки переводчика — хранить их размеченными отдельно от перевода.
- Тафсир (например, Ибн Касира) — отдельное произведение, связанное с аятами связью «толкование», а не версия Корана.
- Текст хранится в двух видах: с разметкой и очищенный для поиска.
- Внешние источники (тексты других религий) — отдельная категория, не первоисточники ислама.
- Связь = адрес ↔ адрес + тип + основание + степень уверенности («заимствование» / «параллель») + обе трактовки.
- Статусы материалов: черновик → на проверке → опубликовано. Очередь «Новые находки» (наводки из соцсетей проверяются по первоисточнику, а не добавляются напрямую).
- Дополнительный слой: видео (ссылки на посты YouTube/Telegram), позже итоги споров; привязан к фрагментам и не меняет ядро.

## Первая фаза

Все разделы из списка выше, кроме дебатов. Все проверки и добавление материалов делает один администратор-модератор через панель администратора (без программирования).

- **Карта Корана:** 114 сур-блоков с клетками-аятами (6236), слои-линзы, карточка при наведении (на телефоне — по касанию), «нити историй». Рисовать на canvas.
- **Базовый ассистент — без языковой модели:** нормализация слов вопроса, словарь терминов и синонимов, полнотекстовый поиск, ранжирование по уровню источника и релевантности, вывод списком и 2D-графом. Собственного текста не пишет. Модель — в следующих фазах через отдельный слой.
- **Сложные темы** (джихад, война, отношение к иноверцам): текст полностью + окружающие аяты + обстоятельства + спектр толкований со степенью признания. Никогда не выводить «голые» цитаты без контекста. Не размещать экстремистские материалы.

## Доступ и безопасность

- Весь сайт — только после входа по логину и паролю; уровней доступа у отдельных материалов нет.
- На время разработки: регистрация только по приглашению, запрет индексации (`noindex`, robots.txt).
- Ограничения по странам — позже, на уровне CDN (Cloudflare).
- Минимум персональных данных при регистрации, обезличенная статистика. Интерес к религии — чувствительные данные.

## Стек (предварительный)

Next.js (RTL) · NestJS (TypeScript) · PostgreSQL (`ltree`, позже `pgvector`) · OpenSearch или Meilisearch · Redis · S3-совместимое хранилище · Python для обработки источников · Docker, CDN. Для быстрого старта допустимо Next.js + Supabase. Окончательный выбор — с автором.

## Технические требования с первого дня

- Арабский текст: нормализация Unicode, поиск с огласовками и без, RTL, проверенные шрифты.
- Языки интерфейса (например, русский, узбекский, английский) отделены от языков источников (i18n).
- У каждого текста, перевода и скана записана лицензия; не скачивать данные с сайтов, которые это запрещают. Скриншот или копия с другого сайта прав не дают.
- Мобильная версия, доступность, резервные копии, проверки при загрузке данных, возможность отката массовой загрузки.
