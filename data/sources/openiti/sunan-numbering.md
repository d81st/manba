# Четыре «Сунана»: отчёт о нумерации при загрузке

Абу Дауд, ат-Тирмизи, ан-Насаи («аль-Муджтаба») и Ибн Маджа из корпуса OpenITI (выгрузки библиотеки «аль-Джами аль-Кабир», CC BY-NC-SA 4.0). У каждого — издание с той нумерацией, которой обычно пользуются при ссылках (её же дают известные сайты): Абд аль-Баки пронумеровал из них только Ибн Маджу, у остальных общепринятая нумерация — от их издателей. Отчёт построен загрузчиком `web/src/lib/import/openiti-narrations.ts`; сверка — скриптом `tools/crosscheck_numbers.py` по второй цифровой копии того же издания из OpenITI (её в репозиторий не кладём).

Что проверяет сверка: для каждого номера, который есть в обеих копиях, совпадает ли начало текста. Расхождение не значит, что ошибка в загруженном файле: ниже выписаны оба начала, решает специалист по печатному изданию.

Из текста везде убраны только служебные пометки (страницы, вехи, ссылки на сноски, которых в выгрузке нет, знаки `*` и `%`). Знаков препинания в этих выгрузках нет. Версии помечены «не сверено».

## Что проверить специалисту

1. Подходит ли выбранная нумерация для каждого сборника (Абу Дауд — Абд аль-Хамид, ат-Тирмизи — Шакир, ан-Насаи — Абу Гудда, Ибн Маджа — Абд аль-Баки) или для какого-то нужна другая (её можно добавить как альтернативную нумерацию).
2. Расхождения со второй копией (таблицы выше) и номера без текста.
3. Десяток случайных хадисов из каждого сборника: совпадают ли номер и текст с печатным изданием или известным сайтом.
