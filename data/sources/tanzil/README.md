# Tanzil

Файлы скачаны с [tanzil.net](https://tanzil.net) 17.10.2026 и лежат **без изменений** (условие лицензии: копировать можно только дословно, уведомление об авторском праве сохраняется).

| Файл | Что это | Версия | Лицензия |
| --- | --- | --- | --- |
| `quran-uthmani.xml` | Текст Корана, Хафс от Асима, письмо усмани | Tanzil Quran Text (Uthmani) 1.1 | CC BY 3.0, без изменений, с указанием источника и ссылкой на tanzil.net |
| `quran-simple.xml` | Тот же текст Хафса в обычном письме — для поиска (не показывается) | Tanzil Quran Text (Simple) 1.1 | CC BY 3.0, без изменений, с указанием источника и ссылкой на tanzil.net |
| `quran-data.xml` | Метаданные: суры, джузы, хизбы, манзили, руку, страницы, саджды | Tanzil Metadata 1.0 | CC BY |

Загружаются в базу скриптом `web/scripts/import-sources.ts` при запуске сайта (один раз; повторный запуск ничего не меняет). На сайте указывается источник со ссылкой на tanzil.net.

Не загружаются пока: виды саджды (`sajdas`, «обязательная / желательная») — оценка различается между правовыми школами, подача ждёт специалиста.

Обновления текста: https://tanzil.net/updates/ — новая версия загружается как новая версия текста, старая не меняется.
