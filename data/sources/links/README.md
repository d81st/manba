# Похожие тексты в разных сборниках хадисов

Пары хадисов из разных сборников, у которых совпадает значительная часть слов. Решение автора 24.10.2026: такие пары показываются на сайте сразу, с пометкой «найдено автоматически по совпадению слов, не проверено» и долей совпадения. Это **не утверждение, что два текста — один и тот же хадис**, а только мера совпадения слов, как в поиске. Пары, которые подтвердит человек, позже будут помечены отдельно.

| Файл | Что это |
| --- | --- |
| `similar_texts.py` | Инструмент сравнения (Python 3, без сторонних библиотек) |
| `similar-texts-v1.tsv` | Результат, способ 1: `адрес A <TAB> адрес B <TAB> доля`, по одной паре в строке, A < B |

**Способ 1.**
- **Цепочка передатчиков отбрасывается.** Сравнивается только текст после первой формулы благословения («صلى الله عليه وسلم», «صلى الله عليه وآله», «عليه السلام»). Если формулы нет, сравнивается весь текст.
- **Текст — набор пар соседних слов.** Слова берутся в виде для поиска: без огласовок, с объединёнными вариантами букв.
- **Формулы не учитываются.** Пары слов, которые встречаются больше чем в 400 текстах, — это формулы («сказал посланник Аллаха» и т. п.), а не слова самого хадиса. Они не делают два текста кандидатами.
- **Доля** = общие пары слов / пары слов более короткого текста.
- **В файл попадают** пары из разных сборников с долей от 0,60 и хотя бы пятью общими редкими парами слов.

**Как читать долю** (проверено чтением случайных пар 24.10.2026): от 0,60 — почти всегда один и тот же хадис в разных передачах (примерно 5 из 6); от 0,40 до 0,60 — часто только общая фраза, поэтому такие пары не берутся. Совпадение ниже 1,00 — обычное дело: сборники передают один хадис разными словами. Со шиитским «аль-Кафи» пар мало: у него другие цепочки и формулировки.

**Как получить заново** (на базе, где загружены все сборники):

```bash
psql "$DATABASE_URL" -c "\copy (SELECT t.address::text, w.id, t.search_plain FROM texts t
  JOIN text_versions v ON v.id = t.version_id AND v.is_primary AND v.status = 'published'
  JOIN works w ON w.id = v.work_id AND w.category = 'hadith') TO 'texts.tsv'"
python3 -I similar_texts.py texts.tsv > similar-texts-v1.tsv
```

Результат 24.10.2026: 77 115 текстов, 49 053 пары. Если способ или тексты изменятся, результат кладётся новым файлом (`-v2`) и загружается новой партией; старые пары не меняются.
