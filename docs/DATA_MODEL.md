## Загрузка

`web/scripts/import-sources.ts` при каждом запуске сайта (Tanzil Uthmani — главная версия `quran.ar.hafs`; Tanzil Simple, если файл есть, — версия `quran.ar.hafs-simple` для поиска) (после миграций) загружает файлы из `data/sources/`, если такая версия ещё не загружена. Перед записью проверяется всё: число сур и аятов, порядок, совпадение с метаданными, существование адресов делений, уведомление о лицензии. Загрузка идёт одной транзакцией: при любой ошибке не записывается ничего. Версия текста публикуется только после записи всех текстов.

Откат загрузки: пока версия не опубликована, всё с её `batch_id` можно удалить. Опубликованное не удаляется, а снимается (`retired`) — это сделает панель администратора.
