# Схема адресов — черновик для утверждения

Черновик · 17.10.2026 · статус: **Коран утверждён автором (17.10.2026); остальное — на согласовании со специалистом**

Адреса фрагментов нельзя будет переименовать после запуска, а таблицы базы строятся вокруг них. Поэтому схему нужно утвердить **до первой миграции**. Ниже — предложение и вопросы к специалисту. Все решения можно менять, пока не написана первая миграция.

Образец устройства — модель данных Sefaria (см. `docs/PLAN.md`, раздел «Схема адресов»). Содержание у нас своё.

## 1. Общие правила

- **Идентификатор произведения** — короткое латинское имя: строчные буквы, цифры и `_`. Например: `quran`, `bukhari`, `muslim`, `kafi`, `tafsir_ibn_kathir`. После публикации не меняется и не используется повторно.
- **Машинный адрес** — идентификатор произведения и номера уровней через точку: `quran.2.255`. В базе он хранится как путь `ltree`, поэтому поиск «всё внутри суры 2» — один быстрый запрос.
- **Читаемый адрес** строится из машинного по языку интерфейса: «Коран 2:255». Отдельно не хранится.
- **Диапазон** — через дефис: `quran.2.255-257`. Диапазон через границу главы — `quran.2.286-3.5` (поддержать позже, если понадобится).
- **Самая мелкая единица** (сегмент) — то, на что ссылаются: аят, хадис.
- **Снятый адрес** не удаляется: он помечается как снятый, а ссылка ведёт на пояснение.

## 2. Коран — утверждено

Утверждено автором 17.10.2026:

| Уровень | Номер | Пример |
| --- | --- | --- |
| Сура | 1–114 | `quran.2` |
| Аят | номер внутри суры | `quran.2.255` |

- **Счёт аятов.** Разные традиции считают аяты по-разному: в издании по Хафсу принят куфийский счёт (6236 аятов), в изданиях по Варшу — другой (мединский), и границы некоторых аятов там не совпадают. Решение: **основной адрес — по куфийскому счёту**, а другие счёты хранятся в таблице альтернативных нумераций с соответствием «один к одному», «один ко многим» и «многие к одному».
- **Кирааты** — версии текста того же аята (`версия` = ривайят), а не отдельные адреса.
- **Басмала** перед сурами (кроме первой, где она входит в счёт) не имеет номера. Решение: хранить её как служебный сегмент с номером 0: `quran.2.0`.
- **Слова.** Для подсветки различий кираатов и словаря может понадобиться адрес слова: `quran.2.255.w3`. Предложение: слова адресуются только внутри системы, в ссылках и цитатах не используются.

## 3. Сборники хадисов

**Решения автора (18.10.2026):** порядок — «Сахих» аль-Бухари и «Сахих» Муслима, затем Абу Дауд, ат-Тирмизи, ан-Насаи, Ибн Маджа; шиитский «аль-Кафи» — как только найдётся текст с понятными правами. Основная нумерация — по Мухаммаду Фуаду Абд аль-Баки (`bukhari.3951`, `muslim.2937`); другие (например, сквозная [7373], «том / книга / номер» переводов) — в таблице альтернативных нумераций. Варианты одного хадиса («21а», «21b») получают отдельные адреса. Остальное ниже — по-прежнему предложение.

**Как это сделано для Муслима (23.10.2026):** `muslim.N` — хадис (группа без своего текста), `muslim.N.K` — его передачи по порядку в издании Абд аль-Баки; читаемо — «Муслим 8a», «8b», …, «8z», «8aa» (буква не показывается, если передача одна); в ссылках принимаются и русские буквы по порядку алфавита («21б» = вторая). Предисловие Муслима — книга 0 в навигации. Подробно — `data/sources/openiti/muslim-numbering.md`.

**Четыре «Сунана» (23.10.2026):** нумерация, которой обычно пользуются при ссылках, — Абу Дауд по Мухйи ад-Дину Абд аль-Хамиду, ат-Тирмизи по изданию Ахмада Шакира и др., ан-Насаи по Абу Гудде, Ибн Маджа по Абд аль-Баки (предварительно, до проверки специалистом). Если номер встречается один раз — адрес `abu_dawud.N`; если под номером бывает несколько текстов — `tirmidhi.N.K`, как у Муслима. Отчёт — `data/sources/openiti/sunan-numbering.md`.

**«Аль-Кафи» (24.10.2026):** изд. аль-Гаффари; хадисы в нём нумеруются заново в каждой главе, книги и главы номеров не имеют. Адрес — `kafi.<книга>.<глава>.<номер>`: книга и глава по порядку в издании (книга 0 — предисловие аль-Кулайни), номер — напечатанный; `kafi.4` — книга, `kafi.4.60` — глава. В «ар-Рауде» номера сквозные через разделы, как в печати. Отчёт — `data/sources/openiti/kafi-numbering.md`.

**«Муснад» Ахмада (24.10.2026):** изд. «ар-Рисаля» (аль-Арнаут и др.), сквозная нумерация 1–27647: адрес `ahmad.N`. Хадисы, добавленные редакторами после N («N/1», «N/2»), — `ahmad.N.k`, на сайте «Ахмад 24009/2», в ссылке на страницу — `/hadith/ahmad/24009.2`. Отчёт — `data/sources/openiti/ahmad-numbering.md`.

Главная сложность: один сборник нумеруют по-разному в разных изданиях и переводах.

Предложение:

- **Основной адрес** — сквозной номер хадиса по одному выбранному изданию: `bukhari.1`. Цитируют хадисы чаще всего именно так.
- **Структура «книга → глава»** хранится как группировка для навигации, но в адрес не входит. Если в другом издании другое деление, адреса не ломаются.
- **Другие нумерации** (другие издания, переводы со схемой «том / книга / номер») — в таблице альтернативных нумераций. По любому из этих номеров можно найти фрагмент.
- **Части одного хадиса** (если в издании есть деление на подпункты) — вопрос к специалисту.

| Пример | Основной адрес | Альтернативная нумерация |
| --- | --- | --- |
| Сборник с единым сквозным номером | `bukhari.N` | номер по другому изданию; том / книга / номер по переводу |
| Сборник, где под одним номером несколько передач (Муслим) | `muslim.N` — хадис, `muslim.N.K` — K-я передача в издании («Муслим 8b» = `muslim.8.2`) | то же |
| Сборник с номерами внутри глав («аль-Кафи») | `kafi.<книга>.<глава>.<номер>` — книга и глава по порядку в издании, номер — напечатанный в главе («аль-Кафи 4.60.3») | том / страница / номер — позже, если понадобится |

Для шиитских сборников, где принято указывать том, книгу, главу и номер, адрес может быть многоуровневым. Схема своя у каждого произведения.

## 4. Тафсиры, жизнеописания и другие книги

- **Тафсир** — отдельное произведение со своей схемой (обычно та же сура → аят, к которой относится комментарий, плюс номер части). Связан с аятами связью «толкование», а не является версией Корана.
- **Тафсир Ибн Касира (решение автора 25.10.2026):** по аятам, как в издании «Дар Тайба». Часть толкования — `tafsir_ibn_kathir.<сура>.<первый разбираемый аят>`, читаемо «Ибн Касир 2:255»; если часть разбирает несколько аятов (2:63–64), ссылка на любой из них («Ибн Касир 2:64») при сохранении превращается в адрес части, а таблица `commentary_ayahs` хранит все её аяты (связь «толкование»). Вторая часть на тот же аят — `.<аят>.2` («2:125b»). Сказанное о суре до первого аята — `<сура>.0`, вступление автора — `0.<n>`.
- **Сира и прочие книги** — схема по изданию: том → глава → абзац, или как решит специалист.
- **«Сира» Ибн Хишама (решение автора 24.10.2026):** том и страница изд. ас-Сакка, аль-Абьяри и аш-Шальби (Каир, 1955) — так на неё обычно ссылаются. Адрес `ibn_hisham.<том>.<страница>` — страница, `ibn_hisham.<том>.<страница>.<часть>` — её часть: страница делится, только если на ней начинается новая глава, чтобы каждая часть принадлежала одной главе. Читаемо: «Ибн Хишам 1:235», часть — «1:235b» (буква — только если частей больше одной). Разделы и главы издания — для навигации, в адрес не входят. Нумерация абзацев не взята: в цифровом файле абзацы размечены ненадёжно (часто разорваны на границе страниц). Другие издания (Вюстенфельд) и переводы — позже, в таблице альтернативных нумераций.
- **Внешние источники** (тексты других религий) — своя категория и своя принятая там схема, например книга → глава → стих.

## 5. Альтернативные нумерации

Одна таблица на все произведения: система нумерации (например, «издание X» или «перевод Y»), номер в этой системе, основной адрес, тип соответствия (точное / часть / объединение).

## 6. Версии текста

Идентификатор версии: `произведение.язык.название` — `quran.ar.hafs`, `quran.ar.warsh`, `quran.ru.krachkovsky`. У каждой версии: тип (оригинал / кираат / перевод), переводчик, источник файла, **лицензия**, статус сверки, признак главной.

## Вопросы к специалисту

1. Коран: какие счёты аятов, кроме куфийского, нужно поддерживать в первую очередь? (Основной счёт и басмала уже утверждены.)
2. Коран: нужны ли адреса для отдельных слов в ссылках, или только внутри системы?
3. Хадисы: по какому изданию берём основной номер для каждого сборника первой фазы?
4. Хадисы: какие альтернативные нумерации обязательны (издания, переводы)?
5. Хадисы: нужны ли адреса для частей хадиса?
6. Шиитские сборники: какие уровни у адреса (том, книга, глава, номер)?
7. Тафсиры: как делить на фрагменты — по аятам, к которым относится комментарий, или по абзацам издания?
8. Какие произведения входят в первую фазу? Это определит, какие схемы нужны сразу.
