# «Священные города»: источники, найденные для черновиков

25.10.2026 · Черновики раздела «Священные города» (`docs/PLAN.md`; категория тем `cities`, страница `/cities`). Каждый город — тема со ссылкой на место на карте; на странице темы показываются события жизнеописания пророка в этом месте.

**Как собрано.** Аяты, хадисы, главы «аль-Кафи» и страницы книг истории, где город прямо назван, — поиском по арабским словам в загруженных текстах; главы «аль-Кафи» взяты целиком по их собственным заголовкам. Это не полный подбор и не оценка: что войдёт в тему, решают автор и специалист. Своих текстов нет — только адреса и короткие отрывки из оригиналов вокруг найденного слова.

**Что в черновиках.** Название, вопрос, место на карте; в поле «Связанные места» — все места ниже. Тексты темы, обстоятельства и позиции сторон пустые: их заполняют автор и специалист, каждую позицию — со своими источниками и степенью признания. Спорные версии (Бекка, место погребения Али) идут позициями с пометкой, кто их держится.

Места на карте — газеттир al-Ṯurayyā (CC BY 4.0), `data/sources/thurayya/`. Тексты — OpenITI (CC BY-NC-SA 4.0), хадисы — издания из `docs/SOURCES.md`, Коран — Tanzil. Ссылки ведут на рабочий сайт (нужен вход).

Итого: 7 городов, 111 мест.
