# Материалы автора

Книги, статьи, полемику и подборки, которые автор присылает «на будущее», храним **не здесь**: `d81st/manba` публичный. Файлы и подробный каталог (что это, сторона, темы, права, утверждения для проверки, темы, ждущие ответа) — в закрытом репозитории [`d81st/manba-materials`](https://github.com/d81st/manba-materials), файл `CATALOG.md`. В облачной сессии его подключают через `add_repo`.

Коротко о правилах (полностью — в `CATALOG.md`):

1. Материал не источник: на сайт попадает только после сверки с первоисточником и проверки прав.
2. Показываются обе половины монеты: тема публикуется, когда собраны и критика, и ответ традиции, у каждой стороны — источники и степень признания.
3. Материалы с призывами к насилию и оскорбительные тексты хранятся как свидетельство, но на сайт не выводятся.
4. Новый материал: файл — в `manba-materials/<дата>/`, строка — в `CATALOG.md`.
