# Материалы автора

Книги, статьи, полемику и подборки, которые автор присылает «на будущее», храним **не здесь**: `d81st/manba` публичный. Файлы и подробный каталог (что это, сторона, темы, права, утверждения для проверки, темы, ждущие ответа) — в закрытом репозитории [`d81st/manba-materials`](https://github.com/d81st/manba-materials), файл `CATALOG.md`. В облачной сессии его подключают через `add_repo`.

Коротко о правилах (полностью — в `CATALOG.md`):

1. Материал не источник: на сайт попадает только после сверки с первоисточником и проверки прав.
2. Собираем все стороны, но без подсчёта «вопрос — ответ»: один ответ может касаться многих утверждений, а другой стороной часто будут сами первоисточники (хадисы, тафсиры). На сайте тема показывает все стороны, какие есть в источниках, каждую со степенью признания.
3. Материалы с призывами к насилию и оскорбительные тексты хранятся как свидетельство, но на сайт как есть не выводятся. Современная пропаганда — у автора, вне git. Классические тексты учёных с суровыми постановлениями (например, фетвы о других течениях) — исторические источники: на сайте только в «Сложных темах», полностью, с историческим контекстом, позицией той группы, о которой идёт речь, и мнениями других учёных.
4. Новый материал: файл — в `manba-materials/<дата>/`, строка — в `CATALOG.md`.
