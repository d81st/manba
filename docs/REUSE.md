# Что ещё можно взять из других проектов автора

17.10.2026, сокращено 08.11.2026 · Готовые решения из [`d81st/avtoexpert`](https://github.com/d81st/avtoexpert) и [`d81st/gameclub`](https://github.com/d81st/gameclub), которые «Манбе» ещё пригодятся. Перед переносом читать оригинал: код там на Express, у нас Next.js, поэтому переносится логика и устройство, а не файлы целиком.

Уже перенесено и из таблицы убрано: учётные записи и роли, защита от перебора паролей, неизменный журнал, миграции при старте, закрытие таблиц от публичных ролей Supabase, подключение с Render, компоненты shadcn/ui, тесты и CI.

## Когда что понадобится

| Наша задача | Откуда взять | Что именно |
| --- | --- | --- |
| Сеансы с поколениями и страница «Устройства» | avtoexpert: `docs/AUTH.md`, `backend/src/modules/auth/sessions.service.ts` | Сеансы в таблице с защитой от копирования токена; закрыть другие сеансы; опасные действия только из сеанса старше 48 ч |
| Журнал действий модератора «старое → новое» | avtoexpert: `backend/src/modules/reports/reportEvents.ts`; gameclub: `backend/src/lib/audit.ts` | Таблица событий без внешнего ключа (записи переживают удаление), слияние частых правок в одну запись |
| Проверки при загрузке и поиск дубликатов | avtoexpert: `reports/contentHash.ts`, `reports/photoFingerprint.ts` | Отпечаток содержимого: одинаковое не загружается дважды, видно «изменено после публикации» |
| Хранение сканов и PDF | avtoexpert: `backend/src/shared/services/fileStore.ts` | Хранилище с двумя драйверами: локальный диск и приватный бакет Supabase Storage |
| Точечные права поверх роли, помощники администратора | gameclub: `backend/src/lib/permissions.ts` | Роли + отдельные права; последнего администратора нельзя снять |
| Проверка «черновик → на проверке → опубликовано» двумя людьми | gameclub: утверждение погашений («четыре глаза») | Своё изменение утверждает другой человек; утверждённое окончательно |
| Офлайн-режим и установка на телефон | gameclub: `frontend/public/sw.js`, `manifest.webmanifest` | Оболочка в кэше, данные — сначала сеть, при обрыве последняя копия |
| Компоненты интерфейса, которых ещё нет | avtoexpert: `frontend/src/components/ui` | dialog, tabs, tooltip, sonner, command, date-picker — по мере надобности |
| Уведомления администратору (новые находки, недоступные видео) | gameclub: `backend/src/modules/telegram/` | Telegram-бот |

## Подводные камни, уже найденные в тех проектах

- **npm 10** падает с `Cannot read properties of null (reading 'edgesOut')` на `npm install`. Обход: `npx npm@11 install` (avtoexpert, `CLAUDE.md`).
- Бесплатный Render засыпает: первое открытие 30–60 секунд; `preDeployCommand` недоступен, поэтому миграции накатываются при старте сервера.
