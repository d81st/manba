# Архив материалов автора

Материалы, которые автор передаёт для будущей работы: книги, статьи, исследования, критические и полемические тексты. **Это закрытый архив, а не библиотека сайта.**

- Файлы лежат здесь без изменений, по папкам с датой получения.
- Каталог с описанием, пользой для разделов и статусом прав — `docs/MATERIALS.md`.
- Сайт эти файлы не показывает и не раздаёт: они вне `web/`.
- В библиотеку сайта материал попадает только обычным путём: проверка прав → сверка с первоисточником → черновик → проверка → публикация.
- Файлы больше 100 МБ в git не кладутся (ограничение GitHub): для них — хранилище Supabase (см. `docs/MATERIALS.md`).
